## [GitLab 修复 CVSS 10.0 关键漏洞，未授权攻击者可读取服务器文件](https://docs.gitlab.com/releases/patches/patch-release-gitlab-19-3-2-released/) ⭐️ 8.0/10

GitLab 于 9 月 10 日发布了紧急补丁（版本 19.3.2、19.2.6 和 19.1.8），以修复一个被评为 CVSS 10.0 分的关键漏洞 CVE-2026-85706。该漏洞存在于代码仓库的 commits API 中，在特定条件下，未认证的攻击者可以利用此路径遍历缺陷读取服务器上的任意文件。 这是一个最高严重级别的漏洞，对广泛用于源代码管理和 DevOps 工作流的自建 GitLab 实例的数据保密性构成了直接且紧迫的风险。成功的利用可能导致源代码、配置文件或凭证等敏感信息泄露，影响无数开发团队和组织。 该漏洞源于 commits API 中路径约束不当和认证缺失的共同缺陷，未能过滤 `../` 等目录遍历序列。受影响的版本包括 GitLab 18.7 至 19.1.8 之前的所有版本、19.2.6 之前的所有 19.2 版本，以及 19.3.2 之前的所有 19.3 版本。GitLab.com 已完成修复，目前尚未出现公开的可复现漏洞利用代码，也无证据表明该漏洞已在野被利用。

**背景**: 通用漏洞评分系统（CVSS）是一个用于评估安全漏洞严重性的框架，评分范围从 0.0 到 10.0。10.0 分代表最高严重级别，通常意味着该漏洞可被远程利用、无需认证且无需用户交互。GitLab 是一个广泛使用的基于 Web 的 DevOps 平台，提供 Git 仓库管理、问题跟踪和 CI/CD 流水线功能。Commits API 是一个 RESTful 接口，允许用户与仓库中的提交数据进行交互。

## [DeepSeek 发布 V4.1 Flash，一款采用新型 Causal-Encoder-Decoder 架构、拥有 552B 参数的多模态模型。](https://t.me/zaihuapd/43770) ⭐️ 8.0/10

DeepSeek 正式发布了 V4.1 Flash 模型，这是其全新模型结构系列中尺寸最小的模型，采用了 552B 参数的 Causal-Encoder-Decoder 结构，输入和输出激活分别为 8B 和 16B，并原生支持多模态视觉理解。该模型已上线 DeepSeek API，模型名为 deepseek-flash，新价格于 2026 年 9 月 10 日生效。 此次发布标志着在使强大、大规模的多模态 AI 变得更易获取和更高效方面迈出了重要一步，因为新型的 Causal-Encoder-Decoder 架构可能在理解与生成能力之间提供了更好的平衡。通过 API 提供这款拥有原生视觉理解能力的 552B 参数模型，使得开发者和企业能够直接使用，这可能会加速复杂 AI 在各类应用中的集成。 该模型架构为其输入层（8B）和输出层（16B）指定了不同的激活规模，这是一个影响其计算资源占用的重要技术细节。此外，公告指出在 2026 年 9 月 14 日之后，对 'deepseek-v4-pro' 模型的请求将被路由至此新模型，这暗示了为现有 API 用户规划了一条迁移或升级路径。

telegram · zaihuapd · Sep 11, 11:32

**背景**: 大语言模型通常基于三种主要架构类型构建：编码器-解码器、因果解码器和前缀解码器，每种架构在处理序列时具有不同的注意力模式。Causal-Encoder-Decoder 是一种混合架构，它结合了双向上下文编码（类似于编码器）和自左向右的自回归解码（类似于因果解码器），旨在提高效率和可解释性。原生多模态模型是从头开始在混合数据（文本、图像等）上训练的，而不是将分别预训练的视觉和语言模型拼接在一起，从而实现更整合的理解能力。
